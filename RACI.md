\# Swarm Intelligence — Draft RACI Matrix



R = Responsible | A = Accountable | C = Consulted | I = Informed

A/R = Both accountable and responsible.

|---|---|---|---|---|

| Requirements and backlog refinement | R | A/R | C | C |

| Literature and industry survey | R | R | R | A/R |

| Frontend / user interface | C | I | A/R | C |

| API / data layer | A/R | C | C | C |

| Plan evaluation and constraint checking | C | C | I | A/R |

| Deconfliction and simulation | C | A/R | I | R |

| Automated testing and validation | R | R | A/R | R |

| System integration and demo deployment | A/R | R | R | R |



We will review this matrix each project phase or sprint and update

responsibilities as needed. Accountability will rotate where appropriate

to the work and sprint goals.
